How I work with AIWie ich mit KI arbeite

I use Claude Code as a coding agent and treat the setup around it as an engineering project of its own (Agent-Setup above).

  • One source of rules. Rules, skills and subagent definitions live in a versioned Obsidian vault. The copies on each machine are checked against it.
  • Plans before code. Larger changes start as a written plan, and only I set a plan to final. The agent never pushes to a code repo without my explicit yes.
  • Rules come from failures. Every rule records why it exists. Example: a handover once listed an already pushed commit as open, so every new session now checks the repo state with Git before it trusts any note.
  • Measure, then optimise. Scripts read the session logs and measure what the vault costs in tokens. After the first measurement the reading required at session start shrank from about 7,800 to about 1,050 words (−86 %).
  • The right model for the task. Documentation goes to smaller models (Haiku, Sonnet), the large model writes the code.

Commits marked "Co-Authored-By: Claude" come from this workflow. The line stays on purpose, so anyone can see where AI was involved.

Ich nutze Claude Code als Coding-Agenten und behandle das Setup drumherum als eigenes Engineering-Projekt (Agent-Setup oben).

  • Eine Quelle für die Regeln. Regeln, Skills und Subagenten liegen versioniert in einem Obsidian-Vault. Die Kopien auf jedem Rechner werden dagegen geprüft.
  • Erst der Plan, dann der Code. Größere Änderungen beginnen als schriftlicher Plan, festlegen kann ihn nur ich. Der Agent pusht nie ohne mein ausdrückliches Ja in ein Code-Repo.
  • Regeln entstehen aus Fehlern. Jede Regel hält fest, warum es sie gibt. Beispiel: Eine Übergabe führte einmal einen längst gepushten Commit als offen. Seitdem prüft jede neue Sitzung den Stand der Repos per Git, bevor sie einer Notiz glaubt.
  • Erst messen, dann optimieren. Skripte werten die Sitzungsprotokolle aus und messen, was der Vault an Tokens kostet. Nach der ersten Messung schrumpfte die Pflichtlektüre beim Sitzungsstart von etwa 7.800 auf etwa 1.050 Wörter (−86 %).
  • Das passende Modell je Aufgabe. Doku übernehmen kleinere Modelle (Haiku, Sonnet), den Code schreibt das große Modell.

Commits mit „Co-Authored-By: Claude“ entstehen in diesem Workflow. Die Zeile bleibt mit Absicht stehen, damit man sieht, wo KI beteiligt war.
